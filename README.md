# WhatsApp Chat Analyzer

A Streamlit-based application for analyzing WhatsApp conversations, message statistics, activity trends, and emoji usage.

## Features
- WhatsApp chat analysis
- Interactive data visualizations
- Message and activity statistics
- Emoji analysis

## Installation

```bash
git clone https://github.com/vaibhavagr1512/Whatsapp-chat--Analysizer.git
cd Whatsapp-chat--Analysizer
pip install -r requirements.txt
streamlit run main.py
```
